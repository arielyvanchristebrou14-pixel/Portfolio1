# Portfolio — Ariel Yvane Brou

Portfolio statique prêt pour GitHub Pages.

## Mise en ligne
1. Créez un dépôt GitHub.
2. Envoyez tous les fichiers à la racine du dépôt.
3. **Settings → Pages**.
4. **Deploy from a branch**.
5. Choisissez `main` puis `/ (root)`.
6. Enregistrez.

Le site utilise uniquement HTML, CSS et JavaScript. Il n'a pas besoin de XAMPP, PHP, Laravel ou MySQL pour GitHub Pages.

Avant publication, remplacez `contact@example.com` dans `index.html` par votre adresse e-mail.
